# CaseTile

Gruppe: Karten

CaseTile (Case Card 84:50): Bild mit Radius 16, die Kennzahl steht im Bild unten links (Satoshi Medium 44 px, Cream) ueber einem Verlauf aus Schwarz, darunter die Bildzeile.

- `adb-tile` > `adb-tile__media` (Bild, optional `adb-tile__badge` mit `adb-badge--photo`), `adb-tile__kpi` (`.v`, `.l`), `adb-tile__lab` (Name Bold, Satz in `adb-fg-muted`).
- Kennzahl nie auf Gesichtern oder Kundenlogos. Bilder ohne Filter.

```html
<a class="adb-tile" href="#" style="max-width:300px"><span class="adb-tile__media"><span class="adb-tile__kpi"><span class="v">489</span><span class="l">(Leads, € 11,77 CPL)</span></span></span><span class="adb-tile__lab"><b>Premium-Neubau, Wien</b><span>Ein Motiv trug die Hälfte aller Leads.</span></span></a>
```

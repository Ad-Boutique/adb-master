# Label

Gruppe: Typografie

Label (Eyebrow): kleine Versalzeile ueber Headlines, Kennzahlen und Karten.

- Klasse `adb-label`: 11px, 700, Sperrung 0.16em, Farbe `adb-fg-muted`.
- Inhalt kurz, zwei bis vier Woerter, im Markup normal geschrieben (Versal kommt aus CSS).

```html
<div style="display:flex;gap:44px;flex-wrap:wrap"><span class="adb-label">Wofür wir stehen</span><span class="adb-label">Auf einen Blick</span><span class="adb-label">Preis je Anfrage</span></div>
```

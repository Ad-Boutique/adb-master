# Header

Gruppe: Navigation

Header: Logo links, rechts Kontakt und Menue als Versal-Links. Auf der Website fix mit `mix-blend-mode: difference`, damit er auf jeder Flaeche lesbar bleibt.

- Klassen `adb-header`, `adb-logo` (der Punkt im Logo mit 55 % Deckkraft), `nav` mit Links. `adb-header--overlay` fuer die fixe Variante ueber Bildern.

```html
<header class="adb-header" style="padding-inline:0"><a class="adb-logo" href="#">ad<i>.</i>boutique</a><nav><a href="#">Kontakt</a><button type="button"><i></i>Menü</button></nav></header>
```

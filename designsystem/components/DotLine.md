# DotLine

Gruppe: Daten

DotLine: die Arbeitsweise als Reihe von Woertern mit Punkten, die sich nacheinander fuellen.

- `adb-dotline` mit `<span>`, gefuellte Punkte `class="on"`. Vier Woerter, klein geschrieben.

```html
<div class="adb-dotline"><span class="on">testen</span><span class="on">messen</span><span>umschichten</span><span>berichten</span></div>
```

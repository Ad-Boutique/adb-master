# DotLine

Gruppe: Daten

DotLine (beibehalten): die Arbeitsweise als Reihe von Woertern, die Punkte fuellen sich nacheinander in Lime mit schwarzem Ring.

- `adb-dotline` mit `<span>`, gefuellte Punkte `class="on"`. Klein geschrieben, 13 px.

```html
<div class="adb-dotline"><span class="on">strategie</span><span class="on">creative</span><span>digital</span><span>growth</span></div>
```

# Wordmark

Gruppe: Marke

Wordmark: "ad.boutique" in Satoshi 780, riesig, am Seitenende im Footer.

- Klasse `adb-wordmark`, der Punkt in `<i>`. Auf Ink ist der Punkt Lime, auf Paper Ink (`adb-accent-text`).
- Es gibt kein Bildlogo: die Marke ist gesetzte Schrift.

```html
<div class="adb-wordmark" style="font-size:96px">ad<i>.</i>boutique</div>
```

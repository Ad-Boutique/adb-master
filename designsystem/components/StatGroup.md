# StatGroup

Gruppe: Daten

StatGroup: eine Reihe Kennzahlen, jede mit einem Lime-Punkt davor.

- `adb-stats` mit `adb-stat`, darin `adb-stat__v` (Amandine, tabellarische Ziffern) und `adb-stat__c`.
- Drei Werte pro Reihe, unter 640px untereinander.

```html
<div class="adb-stats">
<div class="adb-stat"><div class="adb-stat__v">489</div><div class="adb-stat__c">Leads, € 11,77 CPL</div></div>
<div class="adb-stat"><div class="adb-stat__v">€ 5,93</div><div class="adb-stat__c">CPL im zweiten Quartal</div></div>
<div class="adb-stat"><div class="adb-stat__v">+309 %</div><div class="adb-stat__c">Return on Ad Spend</div></div>
</div>
```

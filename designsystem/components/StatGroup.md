# StatGroup

Gruppe: Daten

StatGroup: eine Reihe Kennzahlen, jede mit einem 8-px-Punkt in Textfarbe davor, die Zahl in Amandine (ab 48 px).

- `adb-stats` mit `adb-stat`, darin `adb-stat__v` und `adb-stat__c`. Drei pro Reihe, unter 640 px untereinander. Zahlen brechen nie um.

```html
<div class="adb-stats">
<div class="adb-stat"><div class="adb-stat__v">489</div><div class="adb-stat__c">Leads, € 11,77 CPL</div></div>
<div class="adb-stat"><div class="adb-stat__v">€ 5,93</div><div class="adb-stat__c">CPL im zweiten Quartal</div></div>
<div class="adb-stat"><div class="adb-stat__v">4,02</div><div class="adb-stat__c">BFCM-ROAS, +75 %</div></div>
</div>
```

# Badge

Gruppe: Inhalt

Badge (Figma 99:137): keine Fuellung, 1 px Rand 25 %, Satoshi Medium 13 px, Pill. Kein Punkt, kein Lime.

- `adb-badge`, auf Fotos `adb-badge--photo`. Platz: Bildecke oder Meta-Zeile, nie als Eyebrow ueber einer Headline.
- Ersetzt die frueheren Lime-Pillen der KPI-Karten.

```html
<div class="adb-badges"><span class="adb-badge">Meta, Google, TikTok</span><span class="adb-badge">Lead-Generierung</span><span class="adb-badge">Creative-Testing</span><span class="adb-badge">Ehrliche Attribution</span></div>
```
